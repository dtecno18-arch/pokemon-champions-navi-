# Pokémon Champions 選出ナビ

Pokémon Champions シングル（3対3）の選出支援アプリ。現行版は **v7.1（開発途中）** です。

## 使い方
`index.html` をブラウザで開き、相手の6匹を入力して「選出を決める」を押します。ネットワークに接続できる場合、外部図鑑データの読み込みを試みます。

## テスト
```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python tests/test_app.py
```
GitHub Actions では push / pull_request 時に自動実行します。

## 完成条件（未達項目あり）
- [ ] 対象ポケモン・フォルムの入力網羅性を確認する
- [ ] 3匹の選出理由と相手の選出予測に検証可能な根拠を付ける
- [ ] 初手から終盤の立ち回りを相手構築に応じて説明する
- [ ] 代表的な対戦ケースで判断の妥当性をレビューする
- [x] ソースコードと自動ブラウザテストを同梱する

**注意:** 自動テストが通っても選出の競技的正確性を保証するものではありません。現在の図鑑は外部データ依存で、Champions固有フォルムの網羅性は未検証です。

## 自動化の範囲
GitHub Actions が push / PR ごとにテストします。AIによる定期的な自動改修・自動マージは **未設定** です。これらには別途実行基盤、権限、費用上限の合意が必要です。
