# Pokémon Champions 選出ナビ

Pokémon Champions シングル（3対3）の選出支援アプリ。**開発途中・安定β未認定**です。

## 使い方
`index.html` をブラウザで開き、相手の6匹を入力して「選出を決める」を押します。入力内容は同じタブの再読み込み後も保持され、「クリア」で削除されます。

**現時点では、出典・更新日・個別対面の回答を確認済みのデータが不足するため、選出3匹・先発を推奨せず「選出判断を保留」します。** 名前ベースの脅威表示と入力候補は、実戦の有利不利の証明ではありません。

## 入力候補の検証状況（2026-10-28）
- **固定入力候補351件**（前回349件から2件増）。GameWith掲載の参考母数352形態に対し約99.7%。**公式M-C全件照合は未完了**であり、349/352を「現行レギュレーション網羅率」とは呼びません。
- M-A公式特別セレクト31形態、過去のM-A大会参加可能リスト由来104形態（GameWith二次情報、現行M-C未照合）、M-B追加22種、M-C追加35形態、公式M-A/B/Cのメガ形態81名称（性差込み82形態）と通常種候補76件、フラエッテ（えいえんのはな）などを反映。これらは相互に重複します。
- リージョン、性別、家族数、メガX/Y/Zは候補として区別。重複チェックでは同一種のリージョン・ロトム形態を同一種として扱います。
- **検証済み個別対面：0件**。出典付き脅威情報や名前ベースの対策ルールと混同しません。
- 未収録の名前も手入力できますが、現行M-C使用可否や表記の確認は行われません。

## テスト
```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python tests/test_app.py
```
GitHub Actions は push / pull_request 時にスマホ390px・PC1280pxのブラウザテストを実行します。
